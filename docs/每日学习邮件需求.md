# 每日学习邮件:需求计划

> 状态:需求已确认,2026-10-18。第 1 步的原型在 `debug/learn_mail/`。前情:[美股路线计划.md](美股路线计划.md) 第六节,里程碑 v0.1 之后转向学习功能。

## 一、目标

每天用三分钟,看懂一件真实的股市事件:公司出了什么消息,股价怎么反应,能从中学到什么。

这是学习材料,不是荐股。所有内容只陈述已经发生的事实。

## 二、一份学习材料长什么样

同一份内容,两个出口:

| 出口  | 内容                   | 图                 |
| --- | -------------------- | ----------------- |
| 网页  | 完整版                  | 可交互,点按能看每天的数字     |
| 邮件  | 文字和结构与网页完全相同,末尾附网页链接 | 同一张图的静态版,放在正文对应位置 |

两种图来自同一份图表定义,自动生成,不会出现网页和邮件不一致。

结构沿用苹果财报示意页:

1. 这是哪家公司
2. 发生了什么
3. 股价怎么反应,和大盘对比
4. 以前也这样吗,同类事件全部摆出来数一数
5. 能学到什么
6. 词表

另加一个**先猜再看**的环节:

- **新事件**发生当天只能写到第二天的反应,请你猜之后会怎么走,回看邮件再补上后续。
- **历史案例**的结果已经知道,邮件先停在"猜一猜",答案放在分隔线下面。

## 三、内容从哪里来

- **新事件**:每天从选定的公司范围里,挑一件最适合学习的事。
- **历史案例**:先整理十到二十个候选给你看,你确认后才使用。
- **回看**:新事件发生后若干个交易日,发一封回看邮件。
- **"为什么"那一步**:找不到可靠来源时,明确写"这一步没有答案",不编。

## 四、你需要做的

- 在自己的 `.env` 里加三行发信配置,到时候我给你具体内容。
- 手机上保持 Tailscale 开着,网页链接才能打开。网页只对你自己可见,不公开。

## 五、分三步做

1. **先做一份历史案例,手动发给你。** 用苹果那份内容,确认网页、邮件、静态图、链接都正常。
2. **加上新事件的自动挑选和回看。**
3. **接定时任务。**

## 六、风险

- **新闻覆盖不够。** 现有新闻源不一定覆盖到某家具体公司,这时"为什么"那一步只能留空。
- **挑选标准需要调。** "最适合学习"的规则第一版一定不完美,要靠你的反馈来改。

## 七、已经决定的事

1. **新事件的公司范围**:由 AI 选定,先用美国市值最大的五十家左右。
2. **回看时长**:一周。
3. **没有好事件的日子**:发一个历史案例。
